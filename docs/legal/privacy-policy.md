# Privacy Policy

**Effective date:** November 17, 2026

Vaultime is a local-first desktop application for tracking PC game playtime. This policy explains what data it keeps, where, and why.

The controller responsible for this data under the GDPR is Dominik Schwimmbeck, reachable at [vaultime@outlook.de](mailto:vaultime@outlook.de).

## 1. Data on Your Device

Everything below stays on your device unless you choose to back it up to a cloud server:

- **Game library.** Titles, executable paths and install folders.
- **Session history.** Start and end times, runtime, active and idle time, and integrity records.
- **What you write down.** The status you give each game, notes on sessions, sessions you add by hand and the reasons you give for corrections.
- **Earlier playtime.** If you import it, the playtime Steam counted for the games in your library and when you last played them there.
- **Artwork.** Images found in your game folders or imported by you, plus cached thumbnails.
- **Programs seen running.** For a program from your game folders that runs in front without being in your library: its path, a title made from its folder or file name, how long it ran in front and when it was first and last seen, so Discover can offer it. This stays on your device and is left out of backups.
- **Programs Discover offered.** The paths of the programs Discover showed you, so it offers each one only once.
- **Settings.** Tracking preferences such as the idle threshold.
- **Device identity.** A random ID created on the first start, used to tell your devices apart in your history.
- **Logs.** Technical log files in the app's log folder, used for troubleshooting.

This data lives in the app's data folder on your computer. Vaultime does not send it anywhere on its own.

## 2. Cloud Backup on a Server You Choose (Optional)

We do not run a cloud backup service. Cloud backup works with a Vaultime server that you or someone you trust sets up, and whoever runs that server is responsible for the data on it. Vaultime contacts a server only once you turn cloud backup on and enter its address, and sends it your data only after you sign in. A Vaultime server stores:

- **Account.** Your email address, whether the account may sign in, and when it was created and last signed in.
- **Password.** Only an Argon2id hash, never the password itself.
- **Sign-in sessions.** Hashed refresh tokens with their expiry and the name and version of the app, which it sends with each request.
- **Devices.** A random device ID generated by the app, the device name, the platform and the app version. For each of your devices also the public keys it signs its history with, which the server keeps once registered, so another of your devices can check a backup it merges.
- **Backups.** An archive of your local data that is encrypted on your device before upload. The key comes from your backup passphrase, which never leaves your device, so the server cannot read the archive. Next to it the server keeps unencrypted metadata: a label, size, checksum, timestamps, the app version, your device ID and the number of games, sessions and artwork files. The name you gave the device is stored with it encrypted with your key, so the server cannot read it.
- **Artwork.** Every image is encrypted on your device the same way and uploaded once, then shared by all backups that contain it. The server knows how many images you store, their encrypted sizes and which backups use them. Each image is named by a code made from the image and your key, so the server cannot read an image or match it with anyone else's. Its size stays visible, and covers of well known games have well known sizes, so a size can hint at a game.

The server does not store IP addresses in its database. To slow down password guessing it counts requests per IP address and failed sign-ins per email address in its memory, holds them only as hashes and never writes them to disk.

## 3. Data We Do Not Collect

- No analytics or telemetry.
- No crash reports.
- No advertising identifiers or behavioral profiling.
- No cookies and no tracking on the website. It loads nothing from other services, its fonts come from the same server.
- No data from other programs. To detect games and tell active from idle time, Vaultime reads which programs run, which window is in front and when you last used the keyboard, mouse or a controller. It keeps only that input happened, never which key or button, and stores nothing from it but the resulting active and idle time. To find games it reads the install lists of game launchers, and when you import earlier playtime it reads Steam's playtime file once. It keeps only what belongs to games in your library and the programs seen running listed in section 1, and it notes no program outside your game folders.

## 4. Third Parties

The website, the downloads and app updates come over HTTPS from a server operated by the Vaultime maintainer, rented from IONOS SE, which runs the hardware as a processor on the maintainer's behalf. Like any web server it sees your IP address while it answers a request, and it keeps no access logs. This serves our legitimate interest in delivering the website, the downloads and updates (Art. 6(1)(f) GDPR).

Email to and from [vaultime@outlook.de](mailto:vaultime@outlook.de) goes through Microsoft Outlook.com. Microsoft processes these messages and the addresses in them to deliver and store them. We use your messages only to answer you, which is our legitimate interest (Art. 6(1)(f) GDPR).

No other third parties, such as analytics, advertising or cloud storage providers, receive your data.

## 5. Retention

- **Local data** stays until you delete it or the app's data folder.
- **Data on a cloud server** stays as long as whoever runs that server keeps it. A Vaultime server replaces the oldest backups of an account once it reaches its limits, and it removes unfinished uploads after about an hour.

## 6. Deletion

- Delete local data by removing Vaultime's data folder.
- Delete individual cloud backups from the Cloud page in the app.
- To remove a device from your cloud account, use **Registered PCs** on the Cloud page. Its backups stay.
- To delete your account on a cloud server with all its devices and backups, ask whoever runs that server.

## 7. Security

- Vaultime talks to cloud servers over HTTPS only, and over plain HTTP only to a server on the same device.
- Backups are encrypted on your device with XChaCha20-Poly1305 before upload. Each backup carries a check value made from your key, so a wrong passphrase is noticed. It reveals nothing about the key.
- Sign-in secrets and the backup key on your device are kept in your operating system's credential store.
- Session history is kept in hash chains, so silent edits can be detected. They cannot be prevented.

## 8. Children

Vaultime is not directed at children under 16. We do not knowingly collect data from children.

## 10. Your Rights

The data on your device is yours to read at any time. Settings, Export saves your sessions as CSV or JSON, and a local backup copies all of it.

For data a cloud server holds about you, contact whoever runs it. For data we hold about you, such as email you sent us, you can ask for a copy, have it corrected or deleted, restrict its processing, receive it in a portable format and object to its processing. Write to [vaultime@outlook.de](mailto:vaultime@outlook.de). You can also complain to a data protection supervisory authority.
