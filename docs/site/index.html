Vaultime

A local-first, cross-platform game playtime tracker with integrity verification. Know exactly how long you've played with honest trust labels.

Download View on GitHub

Features

Automatic Tracking

Detects running games and records sessions automatically. Distinguishes active play from idle and background time using native OS signals.

Integrity Verification

Sessions carry trust labels backed by hash chains and monotonic time comparison. A later self-hosted backup layer can add stronger server-side verification.

Local First

All data lives on your machine in a SQLite database. No account required. No telemetry, no analytics, no tracking of your tracking.

Invite-Only Cloud Backup

The remote path is moving toward an invite-only backup beta on your own VPS instead of a public paid cloud service.

Auto-Discovery

Detects Steam libraries and scans common install folders. Import your entire game collection in one click instead of adding titles manually.

Cross-Platform

Runs on Linux, Windows, and macOS with native activity-detection signals on each platform. Built with Tauri for a lightweight, native-feeling app.
