# How Vaultime works

Vaultime counts how long you play your PC games, keeps active and idle time apart and writes every session down like a journal. These pages explain how it counts, what its labels mean and where your data lives.

![The Vaultime library with the game playing now, the past week in numbers and the games to continue](../../../assets/screenshots/library.png "The library opens on the game you play now, tinted from its cover.")

## The short version

Local first
: Everything stays on your PC. There is no account to make and nothing to set up. Cloud backup is an optional extra.

Three kinds of time
: Runtime is how long a game was open, active time is how long you actually played and idle time is the rest. See [How playtime is counted](counting.md).

A history you can check
: Every session keeps a log that only grows, and each PC keeps a signed ledger of its sessions. Changes made outside Vaultime show up as a label. See [Trust labels](trust-labels.md).

Windows and Linux
: Both are supported the same way, with notes for Wayland in [Platforms and Linux](platforms.md).
